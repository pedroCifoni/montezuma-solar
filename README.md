# Montezuma Solar

Site institucional de uma empresa de energia solar, publicado e em produção.

**[Ver online](https://montezuma-solar.vercel.app)**

## Stack

- **React** + **Vite**
- **JavaScript**
- **ESLint**
- Deploy na **Vercel**

## Como rodar

```bash
git clone https://github.com/pedroCifoni/montezuma-solar.git
cd montezuma-solar
npm install
npm run dev
```

### Scripts

| Comando | O que faz |
|---|---|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run lint` | Análise estática com ESLint |
